# Navigating Sequence Analysis Tools: A Task-Oriented Comparison of TraMineR, TanaT, and Sequenzo

## English

This repository is dedicated to a comparative study of three tools for sequence analysis: **TraMineR**, **TanaT**, and **Sequenzo**, conducted as part of my Master's (M2) internship.

It contains the code used to perform a task-by-task comparison of these tools, as well as alternative implementations developed when certain functionalities were not available in a given package.

The full comparison report is available on HAL: [Read the full report on HAL](https://hal.science/view/index/docid/5843804).

*The document is currently undergoing moderation and should be available soon.*

### Repository structure

This repository is organized into three folders, one for each tool.

Each folder contains:
- An `.Rmd` or `.ipynb` notebook containing the code used for the comparison.
- A PDF document displaying the code and its outputs after execution.

For **TanaT** and **Sequenzo**, an HTML version is also provided, which may offer a more convenient way to navigate through the analyses and results.

### Data availability

The analyses rely on data from the **Swiss Household Panel (SHP)**, which are not openly accessible. Access to the data can be requested through [SWISSUbase](https://www.swissubase.ch/en/catalogue/studies/6097/21643/datasets).

However, the primary purpose of this repository is not to investigate the SHP data themselves, but rather to assess the availability and practical implementation of different sequence analysis functionalities across the three tools. The provided PDF and HTML files allow readers to examine the code and its execution without requiring access to the original data.

### Future developments

This repository will be progressively updated to include additional comparisons and implementations, particularly :
- The handling of missing data.
- The analysis of sequences of unequal lengths.

## Français

Ce dépôt est consacré à une étude comparative de trois outils dédiés à l'analyse de séquences : **TraMineR**, **TanaT** et **Sequenzo**, réalisée dans le cadre de mon stage de Master 2.

Il contient les scripts utilisés pour effectuer une comparaison tâche par tâche de ces outils, ainsi que des implémentations alternatives développées lorsque certaines fonctionnalités n'étaient pas disponibles dans l'un des packages.

Le rapport complet de cette comparaison est disponible sur HAL : [Consulter le rapport complet sur HAL](https://hal.science/view/index/docid/5843804).

*Le document est actuellement en cours de modération et devrait être disponible prochainement.*

### Structure du dépôt

Ce dépôt est organisé en trois dossiers, chacun correspondant à l'un des 3 environnements comparés.

Chaque dossier contient :
- Un notebook au format `.Rmd` ou `.ipynb` contenant le code utilisé pour la comparaison.
- Un document PDF présentant le code et les résultats obtenus après son exécution.

Pour **TanaT** et **Sequenzo**, une version HTML est également disponible et peut faciliter la navigation dans les analyses et leurs résultats.

### Disponibilité des données

Les analyses reposent sur les données du **Panel suisse de ménages (SHP)**, qui ne sont pas en accès libre. L'accès à ces données peut être demandé via [SWISSUbase](https://www.swissubase.ch/en/catalogue/studies/6097/21643/datasets).

Toutefois, l'objectif principal de cette comparaison et de ce dépôt n'est pas d'étudier les données du SHP en elles-mêmes, mais d'évaluer les fonctionnalités des trois environnements d'analyse de séquences. Les fichiers PDF et HTML permettent ainsi de consulter le code et les résultats de son exécution sans nécessiter l'accès aux données originales.

### Perspectives

Ce dépôt sera progressivement enrichi avec de nouvelles comparaisons et implémentations, notamment concernant :
- La gestion des données manquantes.
- L'analyse de séquences de longueurs différentes.
